# apps/web

This package owns the single OQS React/Vite SPA. M4 implements the desktop
Project/Activity shell, React Flow project graph, Code, Compare, Backtest, Run
Detail, Pi Chat, Logs, and explicit later-milestone boundary surfaces. The UI
uses only the same-origin browser facade; it never receives raw command,
worker, Pi-state, or artifact-blob authority.

`pnpm start:m4` builds the SPA and formal PyO3 extension, starts the Python
domain and worker against one local data root, registers the bounded Pi
session, and serves both this build and `/api/v1` from one Node process. The M4
formal path uses the pinned synthetic fixture and is not evidence of market
performance.
